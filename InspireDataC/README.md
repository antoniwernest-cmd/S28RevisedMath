# InspireDataC

7 activity HTML files and a separate index.html landing page.

Upload this entire folder (including the inspiree assets subfolder) to your web host. Open index.html to begin a fresh student session. Next/Last navigation preserves answers.

The red dot uses code 259 and fills every activity in this group. PDF Assessment always requests current imported-page answers and recalculates all marks. No credit is awarded for untouched can reserves. Mean is listed once per CatMean exercise, not once per child.
