# EnergyDataD

Grade 2 Ontario Data Literacy, D1.1-D1.5. Six individual Dream HTML activities, plus index.html. 39 available marks. Probability, mean/median and many-to-one graph scales are not included.

Upload the WHOLE folder to Netlify or another static host. Open index.html to start. No external assets or internet libraries are required.

## Activities

1. [Game-card sorting table](Dream.html) — D1.1; 7 marks
2. [Observe the game-card collection](Dream2.html) — D1.2; 5 marks
3. [Concrete graph of game cards](Dream3.html) — D1.3; 14 marks
4. [Game-card pictograph](Dream4.html) — D1.3; 7 marks
5. [A collection with no mode](Dream5.html) — D1.4; 2 marks
6. [Read a game-card Venn diagram](Dream6.html) — D1.5; 4 marks

## Project rules

- A new landing-page entry clears only this group's student session.
- Next/Last navigation preserves answers. Both Next buttons stay in the top/bottom right; they are disabled on the final page.
- Dragged cards can be moved again, including back to their bank. Touch dragging and tap-card/tap-pad are supported.
- The small red dot on every activity opens a blank passcode dialog. Code 259 fills ALL six activities in this group.
- Student ID, per-page timer and Ontario Curriculum button with trillium are included.
- PDF Assessment recalculates from current answers every time. Unanswered items get zero, each mark has one row, and earned/available scores appear per page and overall. Use Print / Save as PDF.
- No student-facing Check button or correctness feedback.
- One-to-one graphs: one object/picture/X/grid interval = one record. Bars start at zero. A tally group uses four vertical strokes crossed by a horizontal fifth stroke.
