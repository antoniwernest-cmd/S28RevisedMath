# Inspire & Energy

Open index.html for the shared landing page. Choose Inspire or Energy, then Monday through Friday. Each day opens the group's existing student entry page.

Upload this entire folder to Netlify, or put its contents at the root of one GitHub repository. The published root must contain index.html, inspire.html, energy.html, portal.css and all ten group folders. No build command is needed. Do not upload only the landing HTML files.

| Day | Inspire | Energy |
| --- | --- | --- |
| Monday | InspireDataA | EnergyDataA |
| Tuesday | InspireDataB | EnergyDataB |
| Wednesday | InspireDataC | EnergyDataC |
| Thursday | InspireDataE | EnergyDataD |
| Friday | InsireDataF | EnergyDataE |

The existing Friday Inspire folder spelling is retained for compatibility. Activity files were copied intact from the current groups. This is a separate upload copy; later changes to original group folders must also be copied here before deploying again.
